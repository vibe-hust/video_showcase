Evolving
Loop Programs

Discovering how frozen transformers should loop.

An offline search procedure lets a language model inspect, edit, and evaluate executable loop programs. The selected program is then frozen and replayed on new inputs without further calls to the search model.

03 Method

Search once.
Replay when needed.

ELP searches over executable programs that determine which blocks repeat, how hidden states are updated, and when computation is reused. Development evidence guides the search; deployment uses the frozen result.

01 / OBSERVE

Read model behavior

Diagnostics inspect intermediate states and execution traces on development inputs.

02 / EDIT

Write a loop program

The search LLM changes structure, state-update dynamics, and execution controls.

03 / SELECT

Keep useful trade-offs

Candidate programs are evaluated and compared under task-specific objectives.

04 / DEPLOY

Freeze and replay

The selected code and settings run on new inputs with no search-LLM call.

↳ The outer loop edits programs offline; the inner transformer loops run during evaluation and deployment.
