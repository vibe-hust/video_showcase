超参数含义
  • layer：参与 loop 的 transformer block 范围（0–29，闭区间）。例如 1-3 表示 block 1、2、3 作为一整组重复执行。
  • K：选中的层组在每次 denoising call 中的总执行次数；K=1 等于不循环（不是“额外次数”）。
  • early-late（采样步窗口）：每个视频 chunk 有 4 次 denoising call，对应 t0=1000、t1≈750、t2≈500、t3≈250。early off = 四步都按 K 循环；early 0-1 = 只在前两步循环，后两步 K 自动降为 1。
  • weak-strong（视频 chunk 调度）：沿视频时间方向共 7 个 chunk。strong_fraction=0.5 表示前 4 个 chunk 用 K、后 3 个用 weak_k（默认 1）；weak off = 全程统一用 K。
  • update mode：standard = 整组层直接重复；ode = 每个完整 pass 后做松弛更新 h + (g(h)-h)/K。
  • XSA：去掉与 value 平行的 attention 分量；batch_infer 默认关闭。
  • 时长：latent_frames=21 → 81 帧 @16fps = 5.06 秒。
  • 复用（黄标）：该组合在此前 sweep 已跑过，直接复用已有视频，未重复生成。
